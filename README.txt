TeachMe synced version.
1. Run supabase.sql once in Supabase SQL Editor.
2. Disable Email Confirmation in Supabase Authentication settings.
3. The Supabase URL and publishable key are already in script.js.
4. Create an account. To make it a teacher, run the SQL shown at the end of supabase.sql.
5. Host the folder on GitHub Pages or another HTTPS host.
The browser key is a publishable key; never add a secret/service_role key.
This version uses a normalized name as an internal email, so names must be unique.
